Sources: [Volkswagen historical archive](https://www.volkswagen-newsroom.com/en/beetle-kaefer-3587), [Wired retrospective](https://www.wired.com/2012/07/july-30-2003-last-vee-dub-marks-the-end-of-an-automotive-era). Illustration is a period Type 1, not the last Puebla model.
